PORTFOLIO WEBSITE

Files:
- index.html: page content
- style.css: responsive dark green styling and animations
- script.js: mobile menu, typing effect, scroll reveal, progress bar and contact form demo
- images/: add your own images here

HOW TO RUN:
1. Extract this ZIP.
2. Open the portfolio folder in VS Code.
3. Open index.html with the Live Server extension, or double-click index.html.

BEFORE PUBLISHING:
- Replace "Your Name" and all sample education/project details.
- Replace your@email.com in index.html and script.js with your real email.
- Replace GitHub/LinkedIn links and project demo/source links.
- The contact form opens the visitor's email application; it does not send through a backend.
- The profile card uses CSS visuals, so no profile photo is required.
